## 核心设定速览

- **灾变**：初寂日——旧都晞京被绝对静默吞没；此后"鸣痕"（凝结成实体的声音残留）降临大陆。
- **两条铁律**：爆音失灵 → 冷兵器 + 声学共振兵器；滞域不能炸 → 阵地防御（塔防）是唯一解。
- **能力者**：聆者，依"谐振印"分职业；无修炼等级体系。
- **核心悬念**：鸣痕也许不是"过去的回声"，而是"先声"——尚未发生之事提前抵达的波。
- **玩法绑定**：视觉小说主线 / LLM 自由对话（倾听即治疗）/ 玩家自制副本（构演厅）。
